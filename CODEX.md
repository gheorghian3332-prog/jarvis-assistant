# CODEX.md — инструкции для OpenAI Codex

Ты — основной исполнитель. Сначала прочитай `AGENTS.md` (обязательные правила) и свою карточку задачи.

## Как тебя запускают
```powershell
codex exec --sandbox workspace-write -C <worktree> "<ТЗ из <файл с описанием задачи>>"
```
Работаешь только внутри своего worktree. Сеть — только для установки зависимостей, перечисленных в ТЗ.

## Шаблон ТЗ (<файл с описанием задачи>)
```
# T<N>: <название>
Контекст: ...
Цель: ...
Файлы (можно менять): ...
Требования: ...
Запрещено: ...
Готово, когда: ...
Проверка: <команды>
```

## Стиль
- Rust: edition 2021, tokio (только нужные features), `thiserror` в библиотеках, `anyhow` только в бинарях,
  без `unwrap()`/`expect()` вне тестов, без лишних аллокаций в горячих циклах, переиспользовать `sysinfo::System`.
  Зависимости — с `default-features = false`, где возможно. Release-профиль: `lto = "thin"`, `opt-level = 3`, `strip = true`.
- Python (только воркеры): типы, `ruff` + `mypy --strict`, pytest.
- TS: `strict: true`, без `any`, функциональные компоненты, состояние в zustand.
- Windows: пути через `pathlib`, кодировка UTF-8 явно, учитывать кириллицу в путях (`C:\Users\example`).
- Сообщения коммитов: `T<N>: <что сделано>`.

В конце выведи отчёт в формате из `AGENTS.md`. Не пиши «готово», если проверки не запускались.
