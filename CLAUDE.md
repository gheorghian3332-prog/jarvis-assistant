# CLAUDE.md — инструкции для Claude Code

Правила для всех: `AGENTS.md`. Архитектура: `ARCHITECTURE.md`. Контракты: `API_CONTRACTS.md`. Как собрать и проверить: `CONTRIBUTING.md`.

## Цикл задачи
1. Прочитай `ARCHITECTURE.md` и нужный раздел `API_CONTRACTS.md`; не читай всю кодовую базу.
2. Работай в отдельной ветке или worktree: `task/<ID>-<slug>`; не коммить в `main`.
3. Проверки (`powershell -ExecutionPolicy Bypass -File scripts/check.ps1`) прогоняй самостоятельно — отчёту другого агента не верь.
4. Нетривиальное — на независимое ревью; изменения безопасности — на ревью отдельно.
5. Обнови `CHANGELOG.md`.

## Экономия
- Не читать файлы целиком без нужды; в описании задач давать пути, а не содержимое.
- Не повторять анализ, который уже записан в `ARCHITECTURE.md` и `docs/`.
